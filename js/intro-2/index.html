Começo do Começo

No HTML eu ensinei a criar a pasta.html e no CSS eu ensinei a linkar ele na pasta.html. Aqui não vai ser diferente e vou ensinar a linkar a sua pasta.js na pasta.html.

Tudo que você coloca de conteúdo fica no <body> e a conexão do seu JS com o HTML vai estar lá. No começo? Não, no final. Ficando assim:

<!-- O caminho está conectado em forma de "rota" | pasta.html -->
1   <body>
2       <script src = "/pasta.js" defer></script>
3   </body>

Avisando com antecedência que em toda página que você quiser que o JS funcione. Você vai ter que linkar o JS em toda página assim como você faz no CSS.

No inicio do código é avisa que ele está conectado em forma de rota. Isso significa que a forma do qual as pastas estão configuradas são em rota. Para mais informações vá em Regras não ditas (Frontend).

Variáveis

O começo é bem simples. Você vai criar duas variáveis. Uma delas vai ser o Menu (btn) e ao clicar nela, você fará com que surja uma
Caixa (box) com o link das páginas.

// Começo - A base do código | pasta.js
1   const btn = document.getElementById('btn-menu');
2   const box = document.getElementById('box-menu');

Está vendo esse código? Pois bem. Deu mais trabalho para pintar ele do que programar o Menu. Seguimos. São duas variáveis para o JS e para o HTML + CSS:

  • btn / box: Java Script
  • btn-menu / box-menu: HTML + CSS

Isso significa que dentro da pasta.js você chama um de btn/box e na pasta.html e na pasta.css você chama de btn-menu e box-menu.

Menu - Abrir/Fechar

O abrir e fechar do menu é tão simples quanto fazer as variáveis.

// Abrir/Fechar ao clicar no Menu | pasta.js
1   btn.onclick = () => box.hidden = !box.hidden

Vou explicar parte por parte do começo ao fim:

  • btn.onclick Ao clicar (onclick) com o mause no Menu(btn)
  • = () => Após o click vai ser aberto o menu
  • box.hidden Aparecendo uma caixa (box.hidden) com os links
  • = ! Clicando novamente o menu fecha e a caixa some

Essa linha serve para que após o usuário clicar no Menu. Ele vai abrir o menu e vai surgir uma caixa. Após clicar novamente no menu a caixa vai sumir.

Nessa caixa você pode colocar textos e o recomendado e o que vai ser ensinado nessa aula: Os links. A aparência da caixa vai ser feita no CSS.
